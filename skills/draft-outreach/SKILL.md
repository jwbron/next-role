# Draft outreach

Read [AGENTS.md](../../AGENTS.md), [outreach guidance](../../guides/outreach.md), the candidate's voice, relevant role files, and tracker.

Ask for the recipient/channel, relationship, desired next step, actual prior contact, and exact role. Don't infer a relationship from a social profile or scrape private contact information. Confirm any evidence or attachment the draft will mention.

Use [outreach.md](../../templates/outreach.md). Write a concise request with a specific reason and a comfortable way to decline. For a referral, make it easy to assess role fit. For a follow-up, include a genuine update or question rather than an invented deadline. Keep private negotiation notes and unrelated interview processes out unless the candidate explicitly wants disclosure.

Save the private draft in the role directory. If a `.txt` paste-ready mirror is useful, register it as a text artifact and validate it. Return the path and pending recipient/attachment checks. The candidate sends the message manually. Don't send it or schedule repeated follow-ups. Mark a referral delivered or update contact status only after the candidate confirms it happened.

## Session checkpoint

Before stopping or changing workflows, save the canonical files and update `session.md` under the selected private workspace using the checkpoint contract in `AGENTS.md`. Record the pending candidate decision and checks actually performed. Honor declined storage, and don't mark a task complete merely because a draft exists.
